**Deep Learning Research — Iranian Traditional Music Classification**

- Developed and evaluated deep learning models for Iranian traditional music classification using TensorFlow, Keras, PyTorch, and FastAI.
- Applied CNN architectures, MobileNetV2, and ResNet152 to image-based classification experiments.
- Used spectrogram representations of audio signals as inputs for deep learning models.
- Implemented transfer learning, data augmentation, and model evaluation using classification reports and confusion matrices.
- Conducted comparative experiments to investigate different neural network architectures and feature representations.
