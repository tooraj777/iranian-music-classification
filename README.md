# Iranian Music Classification using Deep Learning

This project focuses on the Deep Learning-based classification of Iranian traditional music (Dastgah recognition) using Python, TensorFlow, and Keras.

## Project Overview

Iranian traditional music is based on different musical modes called Dastgahs. Recognizing these modes automatically is a complex task that requires advanced audio feature extraction and machine learning techniques.

The goal of this project is to build an intelligent AI system capable of identifying the Dastgah of a performed Setar music sample using Deep Learning models.

## Key Features

* Custom dataset creation for Iranian traditional Setar music
* Audio preprocessing and feature extraction
* Deep Learning model development using TensorFlow and Keras
* Classification of different Iranian Dastgahs
* Model optimization for improved recognition accuracy
* Practical AI application in Music Information Retrieval (MIR)
